# Security Policy

## Supported versions

Only the latest published version receives security fixes.

## Reporting a vulnerability

Please use GitHub Security Advisories:

https://github.com/DevDengChao/yunxin-console-mcp/security/advisories/new

Do **not** open a public issue containing:

- Yunxin cookies or session data
- AppKey / AppSecret
- Callback URLs with embedded credentials
- Customer names, account IDs or other personal data

## Scope

This project talks to the private `frontApi` used by the Yunxin admin console.
It is not affiliated with NetEase. Use it only with accounts you are authorized to manage.
